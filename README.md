# 更好的抖音

一款针对抖音网页版的油猴脚本，去除广告和登录弹窗，支持免登录搜索跳转。

## 功能

- **去除广告**：自动隐藏信息流中的广告内容
- **屏蔽登录弹窗**：自动移除登录对话框及其遮罩层，无需登录即可浏览
- **免登录搜索跳转**：拦截搜索行为，将关键词重定向至免登录搜索结果页

## 安装

1. 安装浏览器扩展 [Tampermonkey](https://www.tampermonkey.net/) 或 [Violentmonkey](https://violentmonkey.github.io/)
2. 点击 [更好的抖音.user.js](./更好的抖音.user.js) 安装脚本
3. 访问抖音网页版即可生效

## 使用说明

| 功能   | 说明                                  |
| ---- | ----------------------------------- |
| 广告屏蔽 | 自动识别并隐藏信息流中的广告和直播内容                 |
| 登录弹窗 | 自动移除登录弹窗及遮罩层                        |
| 搜索跳转 | 点击搜索按钮或回车后，自动跳转到 `/root/search/` 路径 |

## 兼容性

- **匹配域名**: `*.douyin.com`, `*.iesdouyin.com`
- **排除域名**: `creator.douyin.com`
- **运行时机**: `document-start`（页面加载前注入）

## 技术实现

- CSS 选择器屏蔽：通过动态注入样式隐藏已知广告和登录节点
- DOM 清理：使用 `MutationObserver` 持续监控并移除动态插入的弹窗和遮罩层
- 搜索拦截：监听搜索按钮点击和输入框回车事件，重定向至免登录搜索路径
